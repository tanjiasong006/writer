# PDF 默认样式与排版配置

本文件是 PDF 输出样式与文档级排版配置的长期约束（已与产品负责人确认，2026-09-30；尚未实施）。
边界原则见 `docs/decisions.md` 第 5、6、8 节，存储见 `docs/project-format.md` 第 3 节。修改前先与产品负责人确认。

## 1. 原则

- 目标：不做任何设置时，就是一份安静、层次清楚、适合打印与正式交付的中文长文档。
- 配置项少量、语义化、分档（枚举），不提供任意数值、任意系统字体、颜色或针对单个元素的覆盖；
  每种组合的输出质量都由 Writer 保证。
- 配置只作用于 PDF。Word 的默认样式与本文第 3 节看齐（见 `docs/decisions.md` 第 5 节），但不读取 PDF 排版配置。
- 项目中只保存用户改过的项；未改的项始终跟随当前默认值，默认样式改进后旧项目自动受益。
  界面提供"恢复默认"（清空全部改动）。
- 命名的配置组合称为**版式**（`docs/decisions.md` 第 19 节）。应用版式是把它的配置复制进项目，
  项目仍只保存与默认值不同的项。内置版式见 4.1 节。
- 配置修改不提供撤销（既不进入正文撤销历史，也没有独立的配置撤销）。

## 2. 文档信息（内容，不是排版配置）

- 文档新增两项可选信息：**副标题**、**作者**，与文档标题一样属于文档内容，存入 manifest
  并由 `WriterDocument` 表达（修改产生 dirty、随正常保存提交）。
- 两项都是用户输入的纯文本，空值表示不显示。不提供日期（2026-09-30 确认）。
- PDF：显示在封面（关闭封面时显示在首页标题下方）；写入 PDF 元数据（标题、作者）。
- Word：在文档开头的标题下方依次显示副标题、作者（段落样式 `Subtitle`、`Author`）；标题与作者写入文档属性。
  （我的取舍：内容在两种输出中保持一致。）

## 3. 默认样式

### 3.1 页面与结构

| 项 | 默认 |
|---|---|
| 纸张 / 边距 | A4；四边 25mm；页眉和页脚放在边距内，不占正文区 |
| 封面 | 独立一页，不显示页眉和页码。标题 26pt 无衬线加粗，放在页面约 1/3 高处；下接一条细线，再依次是副标题（16pt）、作者（12pt） |
| 目录 | 放在封面之后，由章节标题自动生成，显示到 2 级；条目带引导点和页码。目录页页码使用小写罗马数字 |
| 一级章节 | 另起一页；页面上方先留约 3em，再放章节标题 |
| 页眉 | 左边是文档标题，右边是当前一级章节名；9pt 灰色，下接 0.4pt 细线。封面、目录与每章首页不显示 |
| 页码 | 页脚居中，9pt；正文从 1 开始 |
| PDF 元数据 | 书签（来自章节标题，含编号）、标题、作者、语言 zh |

### 3.2 文字与元素

| 元素 | 默认 |
|---|---|
| 正文 | 衬线 12pt（小四），行距 1.75，两端对齐 |
| 段落 | 首行缩进 2 字符，段间不额外留空。列表、引用、表格、图注内的段落不缩进 |
| 章节标题 | 均为无衬线加粗：一级 18pt，二级 15pt，三级 13pt，四级及更深 12pt |
| 章节编号 | `1`、`1.1`、`1.1.1`，与编辑展示相同 |
| 引用 | 楷体（西文沿用衬线；本机没有楷体时退回宋体），不随正文字体配置变化；左侧 2pt 浅灰竖线，缩进，深灰色文字 |
| 代码块 | 等宽 9.5pt，浅灰底，3pt 圆角，8pt 内边距 |
| 行内代码 | 0.9em，浅灰底 |
| 表格 | 三线表：顶线和底线 1pt，每个表头单元格下方 0.5pt（多行表头中跨列的分组表头下方是短线），无竖线；10.5pt；表头加粗；跨页时重复表头 |
| 图注 | 10pt，居中，灰色 |
| 表注 | 与图注相同的字号与颜色，表格下方左对齐，与表格最后一行在同一页 |
| 分隔线 | 居中短细线，约为正文宽的 30% |
| 链接 | 深蓝色，不加下划线 |
| 颜色 | 正文纯黑，辅助信息只用灰阶，不引入其他强调色 |

## 4. 排版配置项

默认值加粗。所有字体选项都来自 `export::fonts` 的受控字体族。

| 分组 | 项 | 可选值 |
|---|---|---|
| 页面 | 纸张 | **A4** / B5 / A5 / Letter |
| | 页边距 | 窄 18mm / **标准 25mm** / 宽 32mm |
| | 装订 | **单面** / 双面（内侧边距 +5mm、外侧 −5mm；一级章节从奇数页开始；页码与页眉位置镜像到外侧） |
| 文字 | 正文字体 | **衬线** / 无衬线 |
| | 标题字体 | **无衬线** / 衬线 |
| | 正文字号 | 10.5（五号）/ **12（小四）** / 14（四号）；其他元素的字号按比例随之调整 |
| | 行距 | 紧凑 1.5 / **标准 1.75** / 宽松 2.0 |
| | 段落样式 | **首行缩进** / 段间空行（不缩进，段间额外空 0.5em） |
| 结构 | 封面 | **开** / 关（关闭后标题与文档信息放在首页顶部，正文接排） |
| | 目录 | **开** / 关；深度 1 / **2** / 3 |
| | 一级章节另起一页 | **开** / 关 |
| | 章节编号 | **1** / 第 1 章 / 不显示（"第 1 章"只改一级的写法，子级仍为 `1.1`；"不显示"时各级都不显示编号；目录与书签一并遵循） |
| | 页眉 | 无 / 文档标题 / **文档标题 + 章节名** |
| | 页码格式 | **1** / 第 1 页 / 1 / N |
| 元素 | 表格样式 | **三线表** / 网格 |

- 章节编号样式只属于 PDF 排版配置，不改变编辑展示、Word 或章节编号的推导规则：
  编号仍由章节树推导，这里只决定 PDF 中如何书写或是否显示。

### 4.1 内置版式（2026-10-07 产品负责人确认，尚未实施）

版式的概念见 `docs/decisions.md` 第 19 节。内置四种，每种对应一种常见用途，只列与默认值不同的项：

| 版式 | 适合 | 与默认值不同的项 |
|---|---|---|
| 标准 | 一般的长文档、正式交付 | 无（即默认值，应用后项目没有排版改动） |
| 学术 | 论文、研究报告 | 装订双面 · 章节编号"第 1 章" · 目录深度 3 · 行距紧凑 1.5 |
| 书籍 | 书稿、手册 | 纸张 B5 · 装订双面 · 正文字号 10.5 · 章节编号"第 1 章" · 目录深度 1 · 页码"第 1 页" |
| 简洁 | 短报告、内部材料 | 封面关 · 目录关 · 一级章节另起一页关 · 段落段间空行 · 页眉"文档标题" · 页码"1 / N" |

- "学术"不对应任何具体学校的规范，只取国内论文的常见做法；具体规范仍逐项调整。
- 应用版式时，未列出的项回到默认值：项目的排版配置整体替换为该版式的配置，不与原有改动合并。
- 不提供"审阅稿"等其他内置版式（2026-10-07 确认）；增加内置版式前先与产品负责人确认。

## 5. 实现约束

- Domain（`domain/pdf_layout`）：`PdfLayoutSettings`（稀疏，只含用户改过的项）、纯函数 `resolvePdfLayout`
  （合并出完整配置）与 `setPdfLayoutOption`（改回默认值时删除该项）。所有字段都是枚举、布尔或分档数值。
  默认值与 Rust 共享 `src-tauri/fixtures/pdf_layout_default.json`。
- Application：项目会话持有"文档 + PDF 配置"，规则见 `docs/decisions.md` 第 8 节"PDF 配置与项目会话"。
  导出时在同一次操作中捕获内容与配置。
- Rust 只接收语义参数，先解析为 `PageSetup`（纸张、边距、装订）与输出 `Theme`。
  正文区尺寸由 `PageSetup` 计算，替换 `pdf.rs` 中按 A4 + 25mm 写死的 `TEXT_WIDTH_PT` / `TEXT_HEIGHT_PT`；
  图片尺寸上限与表格、图注的预留空间规则保持不变。
- 界面（`PdfLayoutDialog`）：点"导出为 PDF…"后先打开排版设置，主按钮"导出…"；菜单栏"文件 → PDF 排版设置…"
  打开同一面板，主按钮"完成"。设置项分"页面 / 文字 / 结构"三组，以分段控件与复选框表达；左侧是随设置即时重新排版的
  **样张**（2026-10-01 确认，取代先前的页面示意）：用与导出相同的 Typst 排版，取文档开头（前两个一级章节，
  正文总长上限 12000 字，在段落边界截断），渲染前 8 页为 SVG。内容在打开设置时捕获一次；
  排版进行中又有修改时只在完成后按最新设置再排一次。样张的目录与页码只反映样张内容，不是全文分页预览。
  点击样张中的一页打开全尺寸查看：铺满窗口，各页按实际尺寸（100%）竖向排列并定位到该页；只用于查看，
  Esc、点击页面以外或关闭按钮回到设置。修改先作用于草稿，完成 / 导出时写入项目，取消或 Esc 放弃；
  "恢复默认"清空全部改动。文档信息（副标题、作者）在单独的文档信息入口中编辑。
- 双面装订时为凑右页插入的空白页不显示页眉与页码，但计入页码。
- 除样张外，不提供应用内全文分页预览（`docs/decisions.md` 第 8 节）。

## 6. 实施顺序

1. 默认样式：只改 Rust `pdf.rs` 的输出规则（封面、目录、另起页、页眉、首行缩进、三线表等），不涉及配置。（已完成）
2. 文档信息：Domain / manifest / 会话 / Word 与 PDF 输出，以及编辑入口。（已完成）
3. 排版配置的存储与会话：Domain 类型、manifest 字段、保存快照，导出请求携带配置，Rust 按配置生成页面与样式。（已完成）
4. 排版设置界面与 Story。（已完成）
